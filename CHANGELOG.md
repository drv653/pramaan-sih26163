# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-17

### Added
- Interactive prototype dashboard for the Pramaan security assessment platform.
- Seven problem-statement scope domain modules (Authentication, Authorization, Input Validation, API Security, Client-Side, Transport, and Data Privacy).
- Target profiler and attack surface mapping interface.
- Finding state machine visualization (`DETECTED` through `CLOSED`).
- Coverage and Verified-Clean matrix view.
- 0–100 Security Posture Score breakdown with explainability.
- Replayable proof-of-concept cards with deterministic oracle definitions.
- Automated remediation diff guidance and regression test definitions.
- Hash-chained audit trail log viewer and chain verification interface.
- Light and dark theme support with responsive layout.
- Comprehensive technical documentation and architecture specifications in `docs/`.
- Full Product Requirements Document (`docs/PRD.pdf`).
- CI validation workflow for JavaScript syntax and HTML structure.
