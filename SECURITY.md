# Security Policy

## 1. Authorized Use Policy

> **CRITICAL NOTICE:**
> Pramaan is a security assessment framework developed for defensive validation, auditing, and academic research under **Smart India Hackathon 2026 (SIH26163)**.
> 
> **Pramaan must only be used against targets and systems that you explicitly own or have documented, authorized written permission to test.**
> 
> Any unauthorized scanning, testing, or probing of third-party systems, public internet infrastructure, or production domains (including `worldmonitor.app` and any upstream data providers) is strictly prohibited and constitutes a violation of applicable computer fraud and cybersecurity legislation (including the Information Technology Act, 2000).

---

## 2. Reporting a Vulnerability in THIS Repository

We take the security of Pramaan seriously. If you discover a vulnerability or security flaw in the Pramaan codebase, repository, or documentation:

- **Do NOT create a public GitHub issue.**
- Please report vulnerabilities privately through **GitHub Private Vulnerability Reporting** via the repository's **Security** tab (`/security/advisories/new`).
- The repository maintainer (@drv653) will review reports, collaborate with you on a remediation patch, and coordinate a safe disclosure timeline.

### What to Include in Your Report
1. A clear description of the potential vulnerability.
2. The affected file(s), function(s), or component(s).
3. Exact steps to reproduce the vulnerability safely in a local environment.
4. Any suggested fix or remediation steps.

---
